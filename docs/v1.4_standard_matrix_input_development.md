# ProteoDIAPostZ V1.4 Development Notes: Standard Quantitative Matrix Input

This is a development note for the unreleased V1.4 input upgrade. It is not a formal release note, checksum record, or packaging manifest.

## 中文说明

### 标准定量矩阵输入

ProteoDIAPostZ V1.4 支持导入预先整理的 CSV 或 TSV 标准定量矩阵。第一列应为蛋白、基因或其他特征标识，第二列开始每列代表一个样品，定量区域应包含数值或明确的缺失值标记。

由于不同软件和数据处理流程对数值 0 的定义不同，用户必须在导入时选择一种 0 值处理模式：

1. 0 是有效定量值：数值 0 被保留，只有空单元格、仅含空格的单元格、NA 和 NaN 等明确缺失标记被视为缺失值。

2. 0 表示未鉴定或未定量：数值 0、空单元格、仅含空格的单元格、NA 和 NaN 均被视为缺失值。该模式下，0 会在用于分析的矩阵中转换为缺失值，但原始输入信息仍被保留用于追踪。

软件不会根据数据分布或零值比例自动推断 0 的含义。用户应根据上游软件的导出规则和数据处理方式选择正确模式，以避免将真实的 0 值误判为缺失，或将缺失占位符误判为有效定量值。

标准定量矩阵不包含 DIA-NN 或 Spectronaut 的独立鉴定字段，因此软件在该输入模式下将非缺失且符合当前 0 值处理规则的单元格称为“可用定量值”，而不是“蛋白鉴定结果”。相关统计统一报告为“可用定量值数量”。

## English Description

### Standard Quantitative Matrix Input

ProteoDIAPostZ V1.4 supports preprocessed standard quantitative matrices in CSV or TSV format. The first column should contain protein, gene, or other feature identifiers, and each subsequent column should represent one sample. The quantitative data region should contain numeric values or explicit missing-value entries.

Because different software packages and data-processing workflows may use numeric zero differently, users must select one of two zero-handling modes during import:

1. Zero is a valid quantitative value: numeric zeros are retained. Only explicit missing entries, including blank cells, whitespace-only cells, NA, and NaN, are treated as missing values.

2. Zero represents missing or unquantified: numeric zeros, blank cells, whitespace-only cells, NA, and NaN are all treated as missing values. In this mode, zeros are converted to missing values in the analysis matrix, while the original input information is retained for traceability.

The software does not infer the meaning of zero from the data distribution or the proportion of zero values. Users should select the mode according to the export convention of the upstream software and the data-processing workflow. This prevents valid zero values from being misclassified as missing and prevents zero-valued missing-data placeholders from being treated as valid quantitative measurements.

A standard quantitative matrix does not contain the independent identification fields provided by DIA-NN or Spectronaut. Therefore, non-missing entries that satisfy the selected zero-handling rule are described as “available quantitative values,” rather than protein identifications. Related summaries are reported as the “number of available quantitative values.”

## Implementation Notes

- Supported explicit missing-value entries are blank cells, whitespace-only cells, `NA`, and `NaN`.
- `N/A` is not currently treated as an explicit missing-value marker.
- `Inf` and `-Inf` are invalid values and stop import.
- The raw quantitative matrix is retained separately from the analysis matrix.
- The software does not sort features, sort samples, log-transform, normalize, impute, aggregate duplicate features, or infer identifier type during import.
